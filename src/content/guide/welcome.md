这是一篇普通的笔记：可以改、可以删，也可以照着下面的清单一条条试。每做完一件，就把前面的框勾上。

（快捷键按 Windows 写，Mac 上把 Ctrl 换成 ⌘。）

## 先试试这几件事

- [ ] 勾一下这个框。勾选会直接改这篇笔记里的那一行
- [ ] 在下面空一行，行首输入 `/`：标题、待办、表格、公式、流程图……想插什么就从这里挑
- [ ] 输入 `[[`，选一篇笔记，就链过去了。按住 Ctrl 再点链接，会跳到那一篇
- [ ] 按 Ctrl+E，插一个会动的表情
- [ ] 按 Ctrl+K 打开命令面板：搜笔记、日记、目标的正文，也能直接执行命令
- [ ] 点左边的「今日TODO」，写下今天要做的三件事

## 五个区分别是什么

- **笔记**：放各种长期留着的东西。可以建文件夹，把笔记拖进去
- **今日TODO**：每天一篇，就是今天的日记。今天还没写的时候，会先接着显示最近写过的那一天，你一动手改，它才算今天自己的
- **/GOAL**：周、月、年目标，每个周期一篇
- **日历**：点某一天，看那天写了什么。在任何一篇里写 `- [ ] 交周报 @2026-10-09` 这样带日期的待办，它就会出现在日历的那一天
- **归档**：不用了又舍不得删的笔记放这里，随时能恢复

## 写作时用得上的

- 光标进到哪一段，那一段就露出 Markdown 源码；光标离开，又变回排好版的样子
- 某一天和周 / 月 / 年目标里，一行只写 `/模板`，可以从模板开始
- 截图直接粘贴，文件直接拖进来，会存进「附件」文件夹
- Ctrl+F 查找和替换；笔记右上角的「全屏编辑」只留下正文，按 Esc 退出
- 改了笔记的标题，别处链到旧标题的 `[[…]]` 会跟着改
- 删除、归档、移动都能在底部的提示条里撤销

所有语法和快捷键见 [[语法全览]]。

## 你的笔记在哪

每一篇笔记都是一个 `.md` 文件，默认放在「文档 / OnTheWay」文件夹里。用别的编辑器打开也行，改了这里会跟着变。

- 每篇底部的文件夹按钮：在文件夹中显示这篇
- 命令面板里的「更换笔记文件夹…」：换一个地方放，比如网盘里

## 换电脑、找回旧版本

点左下角的「开启同步」，连上你自己的 GitHub 或 Gitee 私有仓库。每台电脑连同一个仓库，改动会自动合并；两边改了同一处，另一版会另存成冲突副本，不会丢。

开了同步以后，每篇底部的时钟按钮能看到它以前的每一版，可以一键恢复。
