这是一篇普通的笔记：可以改、可以删，也可以照着下面的清单一条条试。每做完一件，就把前面的框勾上。

（快捷键按 Windows 写，Mac 上把 Ctrl 换成 ⌘。）

## 先试试这几件事

- [ ] 勾一下这个框。勾选会直接改这篇笔记里的那一行
- [ ] 在下面空一行，行首输入 `/`：标题、待办、表格、公式、流程图……想插什么就从这里挑
- [ ] 输入 `[[`，选一篇笔记，就链过去了。按住 Ctrl 再点链接，会跳到那一篇
- [ ] 按 Ctrl+E，插一个会动的表情
- [ ] 按 Ctrl+K 打开命令面板：搜笔记、日记、目标的正文，也能直接执行命令
- [ ] 点左边的「今日TODO」，写下今天要做的三件事

## 五个区分别是什么

- **文件**：放各种长期留着的东西。可以建文件夹，把笔记拖进去。再点一下左边这个图标，这一栏就收起来，给正文让地方
  - 新建仓库时选文件夹怎么摆：「真实文件夹」就是硬盘上的文件夹，换别的编辑器打开也一样；「逻辑目录」的文件夹只记在 Odea 的树上，不挪硬盘上的文件，排序选「手动排序」就能拖着排顺序，文件夹也能拖来拖去，没放进树里的笔记（比如在资源管理器里直接扔进来的）在「未整理」里
  - 「新建文件夹」旁边还能建「智能文件夹」：写一个条件，比如 `#复盘 updated:30d`，它就自动列出符合的笔记
  - 打开的别的文件夹（比如 Obsidian 的库）按它本来的目录摆；想自己摆的话，命令面板「转成逻辑目录…」，一个文件都不动
- **今日TODO**：每天一篇，就是今天的日记。今天还没写的时候，会先接着显示最近写过的那一天，你一动手改，它才算今天自己的
- **/GOAL**：周、月、年目标，每个周期一篇
- **日历**：点某一天，看那天写了什么。在任何一篇里写 `- [ ] 交周报 @2026-10-09` 这样带日期的待办，它就会出现在日历的那一天
- **归档**：不用了又舍不得删的笔记放这里，随时能恢复

今日TODO、/GOAL、日历合起来叫「日程」，归档单独一个开关：只写笔记、不用日程，也能归档旧资料。新建的仓库两样都开着；打开别的文件夹（比如 Obsidian 的库）时默认都不开，不往别人的文件夹里建日记，要用的话在命令面板里「启用日程」「启用归档」。

## 写作时用得上的

- 光标进到哪一段，那一段就露出 Markdown 源码；光标离开，又变回排好版的样子
- 某一天和周 / 月 / 年目标里，一行只写 `/模板`，可以从模板开始
- 截图直接粘贴，文件直接拖进来，会存进「附件」文件夹
- Ctrl+F 查找和替换；笔记右上角的「全屏编辑」只留下正文，按 Esc 退出
- 改了笔记的标题，别处链到旧标题的 `[[…]]` 会跟着改
- 删除、归档、移动都能在底部的提示条里撤销；删掉的笔记在回收站里留 30 天，隔几天才发现删错了，命令面板「回收站…」里找回来

所有语法和快捷键见 [[语法全览]]。

## 你的笔记在哪

每一篇笔记都是一个 `.md` 文件，放在你的笔记文件夹里（新装时默认是「文档 / Odea」）。用别的编辑器打开也行，改了这里会跟着变。

- 每篇底部的文件夹按钮：在文件夹中显示这篇
- 命令面板里的「更换笔记文件夹…」：换一个地方放，比如网盘里
- 新建的仓库里笔记平放在仓库里，树只有 Odea 认得；想带着文件夹结构离开时，命令面板「导出成真实文件夹…」

## 换电脑、找回旧版本

点左边窄栏下面的云朵图标「开启同步」，连上你自己的 GitHub 或 Gitee 私有仓库。每台电脑连同一个仓库，改动会自动合并；两边改了同一处，另一版会另存成冲突副本，不会丢。新电脑上在启动器里点「从同步仓库拉一份」就行。

开了同步以后，每篇底部的时钟按钮能看到它以前的每一版，可以一键恢复。
