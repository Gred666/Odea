## 0.2.0 · 2026-10-17

- 全局搜索：按 Ctrl+Shift+F（或在命令面板里），在所有笔记、归档、每一天和目标里一起找，按文档分组、带行号；可以区分大小写、全词匹配、用正则。回车直接打开到那一处
- 图片：点一下图片就能改它的地址，源码以一行小字出现在图片下面，图片不再消失、页面也不会跳。鼠标移到图片上，右上角可以查看大图、编辑源码，右下角拖一下直接改大小（双击还原）
- 查看大图：滚轮或触控板缩放，双击在适应屏幕和原始大小之间切换，放大后按住拖动
- 编辑更稳：光标不在正文里（比如在标题上）时不再露出 Markdown 源码；全选后点一下能正常放下光标；拖着选文字时页面不再闪；选中的底色在大字、小字之间对齐了
- 排版重新调过：字体更清晰、正文行距更舒展，标题、行内代码和颜色都重新调了，中文和英文、数字之间自动留一点空
- 更快更省：切换笔记、打字、长列表都更顺；几千篇的笔记文件夹不用等全部读完就能用，侧栏显示读取进度；常驻内存少了约 40 MB
- 自动更新改为只从 GitHub 下载

## 0.1.0 · 2026-10-13

第一个公开版本。

- 笔记：边写边排版的 Markdown，文件夹、`[[双链]]` 和反向链接、粘贴截图和拖进来的附件、表格、公式、流程图、会动的表情
- 今日TODO、/GOAL（周 / 月 / 年目标）、日历：每天一篇，写了日期的待办会出现在日历的那一天
- 所有内容都是笔记文件夹里的 .md 文件，可以放进网盘，也能用别的编辑器打开
- 多设备同步：连上自己的 GitHub 或 Gitee 私有仓库自动同步，两边改了同一处会另存一份，不会丢；每篇都能看历史版本、一键恢复
- 自动更新：有新版本时在后台下好，左下角出现「新版本」，点一下重启就是新版
