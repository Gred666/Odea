## 0.6.2 · 2026-10-29

- 正文改成左对齐，不再两端对齐：在一行中间插字、用输入法打字时，前面已经写好的字不再跟着左右抖
- 开着几个标签（或者分屏、弹出窗口）时，往下滚以后「路径 / 标题」出在标签栏底下一行，读到一半也知道在哪一篇；点标题回到顶上
- 关启动器不再掉帧：不再先缩一下，只是淡出；从启动器打开仓库时，启动器等仓库窗口出来盖住了才退，中间不再透出一下桌面
- 表格里正在编辑的那一格，主色框四边都画满了，贴着表格四个角的格子也不再缺一块；拖图片大小时那一圈、启动器新建仓库时选中那一项的描边同样更清楚

## 0.6.1 · 2026-10-29

- 修了 0.6.0 里窗口会突然整个变白的问题：同一栏里从有标题的笔记换到没有标题的（Ctrl+点击开新标签、切标签、Alt+← 往回走），或者删掉一篇里最后一个标题、在没标题的笔记里写下第一个标题，都不会再白屏
- 打开或关掉「减少动效」时窗口不再变白

## 0.6.0 · 2026-10-29

- 标签页：笔记可以开成一排标签。在列表里 Ctrl+点击（或中键、行菜单「在新标签页打开」，双链上 Ctrl+Shift+点击）在新标签里打开；只开一篇时没有标签栏。Ctrl+W 关、Ctrl+Tab 切、Alt+数字跳到第几个、Ctrl+Shift+T 重新打开刚关的，标签能拖着排顺序。开着哪些标签每个仓库各记各的，下次打开还在
- 分屏：把标签拖到窗口左边或右边拆出一栏（也可以右键「向右拆分」、按 Ctrl+\），最多并排三栏；中间的分割条拖着调宽窄，双击变一样宽。同一篇可以在两栏里同时开着，这边打字那边跟着变，撤销各撤各的
- 弹出窗口：把标签拖出主窗口，或者右键「在新窗口中打开」，它就成了单独的一个窗口，能挪到另一块屏幕上对照着写。关掉它，标签回到主窗口
- 标签里往回、往前走：Alt+← / Alt+→，鼠标侧键也行
- 太宽的块级公式不再一路缩到看不清：先在 `=`、`+`、`−` 后面折成几行，字号不变；只宽一点的整体缩一点；折不开的（大矩阵这种）横向滑动，底下有一根细滑块，拖它不会进到源码里
- 从命令面板打开的对话框（全局搜索、历史版本、回收站、同步、协作……）左上角是「←」，点它或按 Esc 回到命令面板，刚才打的字还在
- 新建、删除笔记时，列表里那一行慢慢展开、收起，下面的笔记不再一下子跳一截
- 标题折成两行时选中，两行中间不再叠出一道深色；标题里有一长串不带空格的英文、数字时，前面的字不再被挤到只剩几个
- 在启动器里打开仓库，启动器关掉之前不再闪一下半透明

## 0.5.1 · 2026-10-28

- 段落下面一行敲 `-`（开始写列表）或 `==`，上面那段不会再一下子变成标题；在几行字和下面的 `---` 中间插一行，也不会整段变成二级标题。现在标题只认一行字、下面跟着三个以上的 `=` 或 `-`
- 用输入法打字时，打到行尾的拼音不再整串跳到下一行、把上面那行字撑开，上屏后也不再缩回去抖一下
- 一篇里有很宽的表格（十几列）时，同一篇的正文和别的表格右边不再被切掉一截；宽表格在自己那一块里左右滑
- 图片、公式、图表滚出屏幕再滚回来，不会又淡入一遍
- 界面大小统一了一遍：左边窄栏的图标大一些、底下几个按钮一样大；笔记列表、搜索框、仓库名的字大一点更好读；列表底下的仓库切换器和正文底下的状态栏对齐在同一条线上；菜单说明、对话框小标题这些小字颜色深一点
- 拖到子文件夹上时那一行的框不再缺两边；历史版本之间留了一点空隙

## 0.5.0 · 2026-10-28

- 可以同时开好几个协作：主持着一篇时再请别人改另一篇，也能一边主持、一边去别人那里做客。协作对话框顶上一排会话，点哪个看哪个；加入请求写清楚要进哪一个。已经在协作里的笔记再点「邀请协作…」，打开的就是那一次
- 做客时打的字，主持人还没存下之前在你这台电脑上留一份：状态栏写着「本机已保留」，存下了变成「已同步给主持人」。主持人那边存不进去、会话断了，这几份在回收站里能存成笔记
- 回收站：命令面板、仓库菜单里「回收站…」，删除的提示条上也有入口。删掉的笔记留 30 天，能搜、能恢复，隔几天才发现删错了也找得回来
- 归档单独一个开关：只写笔记、不用今日TODO 和日历，也能归档。在命令面板或仓库菜单里「启用归档」「关闭归档」
- 新建仓库时选文件夹怎么摆：「真实文件夹」（默认，硬盘上就是这些文件夹，换别的编辑器打开也一样）或「逻辑目录」（文件夹只记在 Odea 里，能拖着排顺序）
- 笔记列表改成一棵树：文件夹和笔记都是同样的一行，点文件夹就地展开、收起，置顶的只在最上面列一次。想看摘要，在排序菜单里打开「显示摘要」。文件夹的「…」里能直接在里面新建笔记，或者「聚焦到这里」
- 字数、日期和几个按钮挪进贴在底下的状态栏，不用滚到最后才看到；收起侧栏的开关也挪到状态栏最左端。正文往下滚以后，窗口顶上淡淡地出现「文件夹 / 标题」，点标题回到顶上
- 仓库窗口打开就是最大化；关的时候什么样（大小、位置、是不是最大化），下次打开就什么样
- 更顺：开关日程、归档不再整页重新加载，停在哪一页还在哪一页；今日TODO 和 /GOAL 之间切换不再闪；光标进到 `**`、`#` 这些语法里，标记马上出来；仓库菜单打开时不再往上跳一下
- 团队仓库：一起编辑时改了笔记的标题，不会再分成两份、各写各的

## 0.4.0 · 2026-10-22

## 0.3.0 · 2026-10-21

- 改名叫 Odea，图标也重新画了。升级后设置、同步的登录和笔记文件夹都原样留着；Windows 上旧的 OnTheWay 快捷方式和安装会自动清掉
- 多个仓库：启动器里列出所有仓库，可以新建、打开电脑上任意一个文件夹、从同步仓库拉一份下来。一个窗口一个仓库，下次打开时上次开着的都回来
- 左边换成一条常驻的窄栏，它右边那一栏可以收起。打开普通文件夹时，文件树就是整个文件夹，图片、PDF 也列出来
- 今日TODO、GOAL、日历成了仓库的「日程」功能，在仓库菜单里开关。打开 Obsidian 的仓库时认它的日记和附件文件夹设置
- 逻辑目录：笔记在树里怎么摆、怎么排，不用挪动文件。可以拖着排序、建快捷方式，没摆好的放在「未整理」里。已有的仓库可以在仓库菜单里转过去
- 智能文件夹：按词、#标签、所在文件夹、最近改过、有没有待办，自动收集笔记
- 导入文件夹，或者把仓库导出成一个普通文件夹，正文里的链接跟着改
- 多人协同编辑：在命令面板里选「邀请协作…」，把链接发给别人，你同意以后对方就能一起写（也可以只读），看得到彼此的光标和名字。同一个局域网直接连；不在一起时能直连就直连，连不上可以自己架一台中继。不经过我们的服务器
- 共享仓库：把整个仓库共享给几个人，大家的改动实时合在一起，成员分管理员、可编辑、只读，每篇都有历史版本
- 标题可以收起：鼠标移到标题左边点箭头，或者按 Ctrl+Alt+[ / ]。右边的目录也能一层层收起
- 换笔记文件夹的位置时可以直接搬过去，跨盘搬完原来的进回收站
- 很长的网址、一长串字母不再把前一行的字撑得很开

## 0.2.0 · 2026-10-17

- 全局搜索：按 Ctrl+Shift+F（或在命令面板里），在所有笔记、归档、每一天和目标里一起找，按文档分组、带行号；可以区分大小写、全词匹配、用正则。回车直接打开到那一处
- 图片：点一下图片就能改它的地址，源码以一行小字出现在图片下面，图片不再消失、页面也不会跳。鼠标移到图片上，右上角可以查看大图、编辑源码，右下角拖一下直接改大小（双击还原）
- 查看大图：滚轮或触控板缩放，双击在适应屏幕和原始大小之间切换，放大后按住拖动
- 编辑更稳：光标不在正文里（比如在标题上）时不再露出 Markdown 源码；全选后点一下能正常放下光标；拖着选文字时页面不再闪；选中的底色在大字、小字之间对齐了
- 排版重新调过：字体更清晰、正文行距更舒展，标题、行内代码和颜色都重新调了，中文和英文、数字之间自动留一点空
- 更快更省：切换笔记、打字、长列表都更顺；几千篇的笔记文件夹不用等全部读完就能用，侧栏显示读取进度；常驻内存少了约 40 MB
- 自动更新改为只从 GitHub 下载

## 0.1.0 · 2026-10-13

第一个公开版本。

- 笔记：边写边排版的 Markdown，文件夹、`[[双链]]` 和反向链接、粘贴截图和拖进来的附件、表格、公式、流程图、会动的表情
- 今日TODO、/GOAL（周 / 月 / 年目标）、日历：每天一篇，写了日期的待办会出现在日历的那一天
- 所有内容都是笔记文件夹里的 .md 文件，可以放进网盘，也能用别的编辑器打开
- 多设备同步：连上自己的 GitHub 或 Gitee 私有仓库自动同步，两边改了同一处会另存一份，不会丢；每篇都能看历史版本、一键恢复
- 自动更新：有新版本时在后台下好，左下角出现「新版本」，点一下重启就是新版
