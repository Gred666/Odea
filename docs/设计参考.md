## 1. 灵感的起点

### 贴边的黑色竖条（用户给的参考图，2026-11-19）

- 是什么：两部手机的屏幕右缘各贴着一条黑色竖条，竖条两头用弧线「长」进屏幕边缘，里面竖排三个圆环进度（73% / 21% / 52%），下面挂着一颗同色的圆按钮（齿轮）；左边那部竖条下面还有一小段弧，像收起来的把手。图片在当天的对话里，没有存进仓库。
- 值得学：
  - 形状像是从屏幕边缘长出来的，而不是浮在上面 —— 贴边处往外翻的凹弯是关键，有一种液体黏在边上的感觉。
  - 挂在下面的圆按钮和竖条同色，读起来是「同一种材料滴下来的一滴」。
  - 平时只露一小段弧，需要时才展开。
- 不足：弧线是圆弧拼的，比例随意，接缝处看得出来（`边栏.md` §3 量过）。
- 用在：边栏改版的刘海、贴边的凹弯、收起后的把手（`边栏.md`）。

## 2. 形状和曲线

### Figma：Desperately seeking squircles

- 地址：<https://www.figma.com/blog/desperately-seeking-squircles/>
- 值得学：圆角好不好看看的是曲率连不连续，不是半径大小；曲率连续的形状读起来「是一个完整的东西」，普通圆角像「方块被做了手术」。把一个圆角拆成「爬坡 — 平台 — 下坡」三段曲率来想；平滑度越大，吃掉的直边越多。iOS 的值是 60%。
- 用在：Odea 的弧线规定（技术方案 §9.6）就是照这个思路，把爬坡换成了 sin²，平滑度 0.6。

### Apple：连续圆角（continuous corner）

- 地址：SwiftUI [RoundedCornerStyle](https://developer.apple.com/documentation/swiftui/roundedcornerstyle)（`.continuous`）；胶囊也有连续版 `Capsule(style: .continuous)`
- 值得学：Apple 从硬件外壳到图标到界面用的是同一种曲率连续的圆角，所以整个系统看起来像一个东西。胶囊（两头圆的长条）也可以是连续的，不一定是两个半圆。
- 用在：§9.6 里胶囊也用规定的弧线，只有正圆例外。

### Apple WWDC25：Get to know the new design system（同心）

- 地址：<https://developer.apple.com/videos/play/wwdc2025/356/>
- 值得学：形状分三种 —— 固定圆角、胶囊（半径 = 高度一半）、同心（半径 = 外层半径 − 间距）。嵌套的东西共用一个圆心，看起来才「装得进去」；贴着屏幕边的控件要和屏幕的圆角同心。
- 用在：刘海里选中块圆角 10、离刘海底边 6，刘海的凸角取 16（`边栏.md` §3.4）；§9.6 的「嵌套要同心」。

### 缓和曲线：铁路、公路为什么不直接接圆弧

- 地址：[The Geometry of Comfort: Transition Curves Explained](https://railwaynews.net/wiki/the-geometry-of-comfort-transition-curves-explained)；[Lambert, Romano, Watling：回旋线和乘坐舒适度](https://www.scitepress.org/Papers/2019/78018/78018.pdf)
- 值得学：直道直接接圆曲线，曲率在接点上突变，乘客会感到一顿；中间插一段曲率慢慢变的缓和曲线就顺了。眼睛沿着轮廓线「走」的时候是同一个道理。回旋线（曲率线性增长）还不是最舒服的，曲率的变化率也连续才更好。
- 用在：§9.6 选 sin² 爬坡（曲率和曲率的变化率在两端都是 0）的理由。

## 3. 层级、状态和展开

### Apple HIG：Live Activities（灵动岛）

- 地址：<https://developer.apple.com/design/human-interface-guidelines/live-activities>
- 值得学：一个进行中的状态有三种样子 —— minimal（只占一个 28pt 的圆）、compact、expanded（点开以后照着原来的样子放大）；展开要「可预期」，展开后的版式和收起时一脉相承。状态平时只占最小的地方，要细看才展开。
- 用在：「O」上的环和点就是 minimal，点「O」出来的控制中心就是 expanded（`边栏.md` §4.4）。

## 4. 提示和帮助

### Apple HIG：Offering help

- 地址：<https://developer.apple.com/design/human-interface-guidelines/offering-help>；老版的 [Providing help tags](https://developer.apple.com/iPhone/library/documentation/Carbon/Conceptual/ProvidingHelpTags/carbon_help_concepts/carbon_help_concepts.html)
- 值得学：提示的字跟着状态变（同一个按钮在不同状态下说不同的话）；越短越好，老规范给的是 60–75 个字符以内。
- 用在：悬停提示的写法（`悬停提示.md` §4.5），「O」的提示随同步状态变。

## 5. 做法（网页上怎么画出来）

### CSS `corner-shape`

- 地址：Smashing Magazine，[Beyond border-radius](https://www.smashingmagazine.com/2026/03/beyond-border-radius-css-corner-shape-property-ui/)；Chrome 团队，[The corner cases of implementing CSS corner-shape in Blink](https://developer.chrome.com/blog/implementing-corner-shape)
- 值得学：`superellipse(K)`、`squircle`、`scoop`（内凹）、`bevel` 这些角的形状，边框、描边、阴影都跟着形状走。Chromium 139 起有，WebKit、Firefox 还没有。
- 用在：§9.6 的落地写法 `border-radius: 1.49R` + `corner-shape: superellipse(1.58)`（K 是拟合出来的，2026-11-19 在 Chrome 156 里画出来核对过）。

### Frontend Masters：Modern CSS Round-Out Tabs

- 地址：<https://frontendmasters.com/blog/modern-css-round-out-tabs/>
- 值得学：标签和下面的内容之间往外翻的圆角（round-out），让标签看起来是从内容里长出来的；网页上的几种画法。
- 用在：还没用上（Odea 的凹弯用 SVG 画，`lib/edgeShape.ts`）。以后标签栏要做「长出来」的样子可以回来看。
