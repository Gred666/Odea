## 3. 缺陷清单（已修 9 条）

### 3.1 `Compartment` 嵌套在 `session` 内导致复用缓存/分屏状态时只读、基准目录、嵌入宿主等配置失效
- **位置**：`src/editor/MarkdownEditor.tsx:134-149, 795-802, 880-920, 1097-1103`
- **怎么触发**：笔记 A 先以可编辑状态打开并切走（状态进入 `stateCache`），随后因非 UTF-8 编码或协作权限变化以 `readOnly={true}` 重新打开（或反向从只读切回可写，或分屏沿用 `twinEditor.state` 时切换 `imageBase` / `embeds` / `attachments` / `collab`）。
- **现象与根因**：`@codemirror/state` 的 `flatten()` 解析扩展时对已登记的内层 `Compartment` 直接取旧状态里的配置，`session.reconfigure(sessionExtensions)` 不会更新嵌在里面的 7 个子 `Compartment`；同时 `useEffect([readOnly])` 用 `readOnlyRef.current === readOnly` 短路，导致重开后的编辑器永久停留在错误的 `readOnly` 状态。
- **修复与验证**：将 `imageBaseSlot`、`wikiImageSlot`、`collabSlot`、`readOnlySlot`（含 `readOnlyGuard`）、`wikiTitlesSlot`、`embedSlot`、`attachmentSlot` 全部提升到顶层 `extensions`，在 `reused.update` 中逐一 `reconfigure`，并将 `readOnly` 的 effect 改为核对 `view.state.readOnly === readOnly`。`src/editor/readOnly.dom.test.tsx` 新增缓存往返切换用例验证通过。

### 3.2 光标在视口外打字触发 `scrollIntoView` 时，`/`、`[[`、`/模板`、`Ctrl+E` 浮层定到屏幕外并吞掉按键
- **位置**：`src/editor/EmojiPicker.tsx:178-226`、`src/editor/MarkdownEditor.tsx:453-472, 528-547, 609-630, 1402-1407`
- **怎么触发**：长文滚到上方后在文末盲打 `/`（或光标靠近视口边缘触发滚动时输入 `/`、`[[`、`/模板`、按 `Ctrl+E`）。
- **现象与根因**：实测无头 Chrome（视口高 `802px`）下，CodeMirror 在同一次 `requestMeasure` 周期里先跑所有 `read`、再在 `write` 阶段改 `scrollTop`；`openSuggest` 的 `read` 读到滚动前的 `top: 2300`，`pinnedEdge` 算出 `bottom: -1492px`（面板落在 `y = 1964..2309` 完全不可见），但最高优先级键表已拦截 `ArrowUp/Down`、`Enter`、`Tab`。此外 `caretAnchor` 兜底误用了随正文滚走的 `contentDOM` 而非可视的 `scrollDOM`。
- **修复与验证**：① `placePicker` 与 `pinnedEdge` 增加 `clampAnchor` 将锚点夹在 `[EDGE, viewport.height - EDGE]` 内；② 事务带 `scrollIntoView` 或量出屏外坐标时在 `write` 阶段排下一帧 `requestMeasure` 按滚完位置重摆，`Ctrl+E` 光标在滚动区外时先 `scrollIntoView`；③ `caretAnchor` 兜底改为 `view.scrollDOM`。`EmojiPicker.dom.test.tsx` 单测与无头 Chrome 实测（`rect: 424..769`，`fits: true`）均验证通过。

### 3.3 右键或中键点击正文替身会误改正文或拆开渲染态
- **位置**：`src/editor/widgets.ts`（13 处 `mousedown`）、`src/editor/math.ts:362`、`src/editor/diagram.ts:96`
- **怎么触发**：在任务勾选框 `.cm-odea-task`、可折叠提示块徽章 `.cm-odea-callout-badge`、公式、Mermaid 图表、HTML 块、注释胶囊、列表圆点、脚注徽章上按鼠标右键（`button === 2`）或中键（`button === 1`）。
- **现象与根因**：上述 `mousedown` 监听未检查 `event.button === 0`。实测无头 Chrome 右键任务框直接把 `[ ]` 改成 `[x]` 触发存盘，右键提示块徽章翻转 `-`/`+`，右键公式/图表立即拆回源码。
- **修复与验证**：统一补齐 `if (event.button !== 0) return;`。`markdownAdvanced.dom.test.ts` 与无头 Chrome 右键实测（`rightClickMutatedTask: false`、`rightClickMutatedCallout: false`）均通过。

### 3.4 `[TOC]` 点击跳转漏掉 Setext 标题并误中代码块 `#` 注释；脚注双向跳转误中代码里的 `` `[^id]` ``
- **位置**：`src/editor/widgets.ts:937-948, 1008-1022`
- **怎么触发**：文档含代码围栏 `# 注释`、Setext 标题（`标题\n---`）及上方编辑偏移后点击 `[TOC]` 条目；或正文先出现行内代码 `` `[^a]` `` / 代码围栏里的 `[^a]:` 再点脚注徽章跳转。
- **现象与根因**：`findHeading` 用原始行正则只认 ATX `#` 且不跳过 front matter 与代码块（实测无头 Chrome 点击 Setext 目录项跳到旧偏移 `375` 而非真实行首 `299`）；`footnoteDefinitionAt` / `footnoteReferenceAt` 对全文字符串直接跑正则，把代码字面量里的文本当成真定义或真引用。
- **修复与验证**：三处统一改走语法树遍历（`ensureSyntaxTree` + `frontMatterRange` + `HEADING_RE` / `FOOTNOTE_DEF_RE` + 跳过代码/公式/HTML 字面量节点）。`markdownAdvanced.dom.test.ts` 与无头 Chrome 实测（`expected: 299, actual: 299`）均通过。

### 3.5 `renderMarkdown` 空任务项重复 React key 告警；`buildOutline` 误收缩进代码、多行注释与公式块里的 `#`
- **位置**：`src/lib/markdown.tsx:298, 336-394`
- **怎么触发**：打开模板选择器（内置日计划模板含两条空任务 `- [ ] `）；或正文中含 4 空格缩进代码、`~~~` 围栏、多行 `<!-- ... -->`、`$$ ... $$` 块内的 `#` 行。
- **现象与根因**：列表 `<li key={\`${key}-${it.text.slice(0, 24)}\`}>` 漏掉下标 `j`，空任务生成重复 key `tpl-day-plan-b2-`；`buildOutline` 用 `/^\s*(#{1,6})/` 匹配任意缩进且未跟踪注释块与公式块，不仅产生假目录项，还会把最浅层级 `shallowest` 拉成 H1 导致真标题缩进错档。
- **修复与验证**：`<li>` key 补入序号 `j`；`buildOutline` 严格按 CommonMark 限制 `0–3` 空格缩进并跳过缩进代码块、HTML 注释与 `$$` 公式块。`TemplatePicker.dom.test.tsx` 与 `markdown.test.ts` 验证通过。

### 3.6 右侧目录树隐藏形态未设 `inert` 导致键盘 `Tab` 掉进 `aria-hidden` 陷阱，且标题含英文双引号时键盘折叠报错
- **位置**：`src/components/Outline.tsx:201-214, 346-368, 707-801`
- **怎么触发**：在大于 1280px 宽窗口按 `Tab` 顺序遍历焦点；或在标题含 `"` 的子节上按 `←` / 点击父节折叠箭头。
- **现象与根因**：实测无头 Chrome 第 16 次 `Tab` 落入 `aria-hidden="true"` 的隐藏目录按钮；专注模式下刻度列与悬停面板两份按钮同时可聚焦；`focus()` 与 `toggle()` 仍把标题 id 拼进 `[data-outline-item="..."]` 选择器，含双引号时在部分选择器引擎抛语法异常。
- **修复与验证**：非激活形态加 `inert` 并在 200ms 交叉淡出后卸载；专注模式悬停副本按钮设 `tabIndex={-1}`；`focus` / `toggle` 改为直接比对 `dataset.outlineItem` 与祖先链 `dataset.outlineGroup`。`Outline.dom.test.tsx` 与无头 Chrome `tabTrail`（全程 `inAriaHidden: false`）均验证通过。

### 3.7 `OverlayScrollbar` 缺少 `pointercancel` 处理导致拖拽失焦后永久卡在拖拽态，且计时器未跟所属窗口走
- **位置**：`src/components/OverlayScrollbar.tsx:112-195`
- **怎么触发**：按住自定义滚动条滑块拖动途中触发系统手势中断或切走窗口（浏览器只派发 `pointercancel` 不派发 `pointerup`）。
- **现象与根因**：未监听 `pointercancel`，导致 `dragging` 永久为 `true`、`pointermove` 一直挂着，此后鼠标滑过即篡改滚动位置且滚动条永不自动隐藏；定时器与 `rAF` 绑在主窗口 `window` 而非 `winOf(scroller)`。
- **修复与验证**：合并收尾逻辑同时监听 `pointerup` 与 `pointercancel`（安全检查 `hasPointerCapture`），全部计时与 `rAF` 走 `winOf(scroller)`。新增 `src/components/OverlayScrollbar.dom.test.tsx` 验证通过。

### 3.8 光标进入独占一行的 `![[笔记]]` / `![[附件]]` 时穿透进普通图片解析并整篇 `doc.toString()`
- **位置**：`src/editor/inlineDecorations.ts:650-662`
- **怎么触发**：光标移到单独成行的 `![[周报]]` 或 `![[说明书.pdf]]` 上打字或移动。
- **现象与根因**：`addEmbed` / `addAttachment` 在展开态返回 `true`，原代码只拦了 `embedded === false`，导致 `embedded === true` 时穿透下去对整篇文档调 `state.doc.toString()` 再跑一遍 `resolveImage`。
- **修复与验证**：`embedded !== null` 时直接分流（`false` 剪枝子树，`true` 仅继续给内部语法标记上色，不再走图片解析）。`src/editor/embed.dom.test.ts` 新增 `doc.toString` 零调用断言通过。

### 3.9 弹出窗口内的动态表情静止帧在切换主题或系统深浅色变化时不刷新配色
- **位置**：`src/lib/paneWindow.ts:38-55`、`src/editor/animatedEmoji.ts:258-277`
- **怎么触发**：将笔记拖成独立弹出窗口（内含视口外或排队静止的 `:odea_fire:` 等动态表情），切换应用明暗主题或系统深浅色。
- **现象与根因**：`watchTheme()` 只查主窗口 `document.querySelectorAll("svg.odea-ae-still")`，漏掉 `registerPopoutWindow` 登记的子窗口 `Document`，且未监听 `prefers-color-scheme` 媒体查询变化。
- **修复与验证**：`paneWindow.ts` 导出 `allDocuments()`，`watchTheme()` 遍历全部打开窗口的 `Document` 更新静止帧 `href`，并补充 `matchMedia("(prefers-color-scheme: dark)")` 监听。`animatedEmoji.dom.test.tsx` 新增跨窗口换主题测试验证通过。

## 5. 性能浪费清单（已修 4 条 + 测试偶发 1 条）

1. **`Outline.tsx` 在多小节文档上常驻数百个 Framer Motion 投影节点与隐藏的 `ZenOutline` 树**（`src/components/Outline.tsx:69-84, 216-248, 333-642`）
   - **证据**：200 小节 + 400 任务文档上 V8 CPU Profile 第 1 名热点是 `measureScroll @ motion`（`88.0ms` self，`>133ms` total），右侧栏挂了 `337` 个 Motion 节点与 `737` 个 `<button>`（其中 `468` 个来自平时根本看不见的 `ZenOutline`）；每次打开命令面板或切标签都会触发全局 Motion 布局投影遍历。
   - **修复**：仅保留滚动容器与当前激活项上的 1 个 `layoutId="outline-indicator"` 为 Motion 节点，子树折叠改用原生 CSS Grid `1fr ↔ 0fr`、箭头旋转改用原生 SVG `<path>` CSS `transform`；非当前形态在 200ms 交叉淡出后即卸载。修复后 `measureScroll` 从热点榜消失，`zenButtons` 从 `468` 降为 `0`，命令面板打开 p50 从 `194ms` 降到 `96ms`（−51%），长文启动首屏从 `1297ms` 降到 `662ms`（−49%）。
2. **`OverlayScrollbar.tsx` 在 250ms 高度缓动收敛期间每帧强读 `clientHeight` 与 `scrollTop` 触发同步布局**（`src/components/OverlayScrollbar.tsx:50-115`）
   - **证据**：大文档中间每次换行，CodeMirror 行高回填触发 `ResizeObserver` 后滑块缓动约 15–24 帧，每帧读 `scroller.clientHeight` / `scroller.scrollTop` 强制同步布局，占火焰图第 2 热点（`31.6ms` self）。
   - **修复**：缓存 `clientH`（仅在 `stale` 时读取）与 `scrollTop`（仅在 `stale` 或 `scrolled` 时读取），纯缓动收敛帧零布局读取。修复后从热点榜消失，`FireAnimationFrame` 耗时减半（`>290ms → 144ms`）。
3. **可见图片每次行内装饰重建无条件 `state.doc.toString()`，缩写高亮每键重编译全部正则**（`src/editor/images.ts:14-39`、`src/editor/inlineDecorations.ts:181-185, 655-668, 1025-1066`）
   - **证据**：43.7KB 含 6 张可见图 + 6 个缩写的笔记打字时，每张普通 `![alt](url)` 图片都调一次 `state.doc.toString()` 拼整篇字符串，每个缩写词每键 `new RegExp(..., "gu")` 全段扫描。
   - **修复**：`parseImage` / `resolveImage` 改为按需惰性求值函数（仅 `[alt][ref]` 引用式图片才取一次全文并按轮次缓存）；缩写正则按词缓存（上限 256）并先用 `source.includes(abbreviation)` 快速跳过。多图多缩写文档打字 p50 `36 → 29 ms`、p90 `70 → 47 ms`（−33%）。
4. **`useEditorHost` 在无关 `useData` 状态更新时每次遍历全部笔记拼接指纹字符串**（`src/components/editorHost.ts:39-62, 102-104`）
   - **修复**：按 `(state.notes, state.archived)` 数组引用缓存 `linkKey`，自动保存状态、草稿、正文缓存变化时 `O(1)` 直接命中，零数组与字符串分配。
5. **`embed.dom.test.ts` 固定 `setTimeout(20)` 在并行全量跑时偶发超时失败**（`src/editor/embed.dom.test.ts:34-44, 118-126`，对应 `TODO.md` 挂账项）
   - **修复**：将固定 20ms 等待替换为 `vi.waitFor` 等待所有 `.cm-odea-embed-body` 异步渲染落盘，全量 166 文件并行回归稳定通过。
