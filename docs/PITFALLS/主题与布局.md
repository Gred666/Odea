# 主题 / 布局

- Tailwind v4 的 `dark:` 变体需要 `<html>` 上有明确的 `data-theme`，不能只靠 `prefers-color-scheme` —— `index.html` 里有段内联脚本在首帧前落属性。
- 标题栏的 `data-tauri-drag-region` 铺满顶部 38px，这一条内会吞掉滚轮事件。各视图内容都从 42px 以下开始。
- `win_start_dragging` 必须在 mousedown 的同一调用栈里发起 IPC，不能等动态 import。
- Browser 预览面板的截图会滞后于动画，判断渲染问题要用 DOM 测量而不是看截图。
- Tailwind 的 preflight 给 `sub`、`sup` 加了 `position: relative` 和 `bottom: -0.25em` / `top: -0.5em`：只改 `vertical-align` 对不齐别处的上下标（白板的静态卡片对编辑器的 `.cm-odea-sup` 差 5.4px，2026-11-22），要连 `top` / `bottom` 一起清掉。
- **带 `cqw`、`%` 的式子放进自定义属性，在「用它」的那个元素上才解析**（2026-11-24，`globals.css` 的 `.odea-column`）：没注册的自定义属性往下传的是那一串字，不是算好的长度。
  `--odea-column-push: clamp(0px, calc(100cqw - …), …)` 写在正文列上、在列里面的 `.odea-notch-clear` 用，`100cqw` 量的是离**用的那个元素**最近的尺寸容器 —— 两处正好是同一个容器才对得上。
  同理带 `%` 的放进 `padding` 是按用的那个元素的包含块算。想让它「算好了再传」得用 `@property` 注册类型
