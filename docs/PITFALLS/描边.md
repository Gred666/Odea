# 描边落在整物理像素上

用户的说法是「边框没显示完颜色，一般是边缘区域」（2026-10-29 表格编辑中的格子）。

- 描边、焦点框用 `border` / `outline`：粗细浏览器取整到物理像素。不用 `box-shadow` 的扩展（包括 Tailwind 的 `ring-*`）
  画主色描边：不取整，1.5px 在 1 倍屏上是一排实色一排半透明，`ring-1` 在 1.25、1.5 倍屏上同样。很淡的分隔色看不出来，可以留着
- 圆角、`overflow: hidden` 的容器（表格外框）里贴着角的描边会被圆角裁掉一截：角上那一格的描边跟着容器的内圆角走
- 全局 `:focus-visible` 带 6px 圆角（`globals.css` 的 base 层），输入框、`contenteditable` 一聚焦就命中：
  有底色、本来是方的元素要自己写 `border-radius`

怎么逐像素验：`VERIFICATION.md`「逐帧对比」。
